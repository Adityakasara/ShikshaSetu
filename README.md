# ShikshaSetu

ShikshaSetu is a Flutter-based mobile application built to support students through a simple, clean, and user-friendly interface. The app is designed to make academic support and student-focused workflows more accessible through a cross-platform mobile experience.

## Overview

This project was developed using **Flutter** and **Dart** with a focus on:

- Clean mobile UI
- Reusable widgets and structured screens
- Smooth navigation flow
- Scalable code structure for future enhancements

ShikshaSetu is intended to serve as a foundation for a student support platform that can be extended with features like authentication, notifications, backend integration, and real-time updates.

## Features

- Cross-platform mobile app using Flutter
- Responsive and simple user interface
- Modular screen-based architecture
- Reusable UI components
- Easy navigation between app sections
- Scalable codebase for future development

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **IDE Support:** VS Code / Android Studio
- **Platform:** Android / iOS

\\\bash

cd ShikshaSetu

Install dependencies:

flutter pub get

Run the application:

flutter run
Useful Flutter Commands

Check Flutter setup:

flutter doctor

Build APK:

flutter build apk

Build iOS app:

flutter build ios
